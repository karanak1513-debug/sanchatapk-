## Brand & Style

This design system embodies high-conviction personal wealth management, structured through Swiss architectural discipline and optical glass physics. Tailored for private wealth clients and high-net-worth individuals, the interface evokes calm permanence, discretion, and algorithmic authority. Rather than loud fintech motifs, it treats the screen as an engineered lens: pure whitespace, balanced grids, subtle structural glows, and tactile physical feedback.

The aesthetic fuses two primary movements:
- **Swiss Architectural Precision:** Strict baseline rhythm, strict structural alignment, restrained typographic hierarchy, and razor-sharp informational layout.
- **Optic Frosted Glass (Neomorphic Translucency):** Layered milky glass planes with deep backdrop dispersion, micro-hairline borders, and gentle surface refraction that mimics milled crystal floating over atmospheric light fields.

## Colors

The foundation is built upon an architectural Light Mode schema. Surface layering relies on optical transparency over localized ambient light fields rather than opaque gray steps.

### Atmospheric Base & Substrata
- **Base Canvas:** `#F8FAFC` (Off-white architectural ground).
- **Ambient Chromatic Glows:** Generated via sub-surface radial gradients behind glass panels:
  - Wealth Accent Glow: `#FFE4E6` (Soft warm rose ambient light, opacity 35–60%, blur 80px).
  - Structural Atmosphere: `#F1F5F9` (Cool icy slate tint, balancing rose tones).

### Pigment Accents & Content
- **Primary Ink (Obsidian / Deep Slate):** `#0F172A` delivers authoritative readability for headers and primary values.
- **Secondary Ink (Slate Muted):** `#64748B` for analytical metadata, secondary labels, and structural hairpins.
- **Sub-tier Ink (Slate Whisper):** `#94A3B8` for input placeholders, deactivated states, and structural rules.
- **Precision Crimson (Primary Accent):** `#DC2626` serves as an intentional focal point for automated actions, drawdown limits, or critical security states.
- **Emerald Green (Yield Accent):** `#059669` marks verified performance, positive capital velocity, and yield execution.
- **Obsidian Slate (Secondary Button / Pill Base):** `#1E293B` provides dense, weighted contrast for primary actions.

### Glass Physics
- **Glass Panel Face:** `rgba(255, 255, 255, 0.72)` with active background dispersion.
- **High-Spec Glass Face:** `rgba(255, 255, 255, 0.88)` for interactive elevated elements.
- **Hairline Border:** `1px` continuous linear gradient from `rgba(255, 255, 255, 0.95)` at the top edge to `rgba(226, 232, 240, 0.40)` at the bottom edge.

## Typography

The typographic engine uses **Plus Jakarta Sans** for expressive balance and organic authority, paired with **Inter** for dense metadata and strict tabular numerical alignment.

### Rules of Engagement
- **Tabular Figures:** All financial figures, balance indicators, percentage yields, and timestamp calculations must enforce `font-feature-settings: "tnum" 1, "cv05" 1`.
- **Display Weights:** Restrict 700 weight exclusively to `headline-display` balances. Titles and section markers rely on tight tracking (-0.015em to -0.02em) in 600 weight to maintain high architectural density.
- **Hierarchy Separation:** Section headers should pair uppercase `label-sm` tracking with bold architectural `title-md` units to cleanly divide analytical modules.

## Layout & Spacing

Designed specifically for the Android 9:19.5 aspect ratio (e.g., modern Flagship displays at 393×851pt up to 412×915pt), the layout operates on an 8-point base grid using an unyielding fluid structural frame.

### Form Factor Specifications
- **Grid Configuration:** 4-column fluid mobile grid with 16px (`1rem`) gutters and 20px (`1.25rem`) fixed outer margins, guaranteeing thumb-safe clearance.
- **Android Display Safe Zones:** System bar reservation: 48px top status area and 32px gesture navigation baseline. Key execution controls must be anchored inside a persistent 64px floating glass toolbar suspended 16px above the navigation barrier.
- **Rhythm & Padding:**
  - Card Interior Padding: Standardized to `space-lg` (24px) for master balances, `space-md` (16px) for ledger items.
  - Section Spacing: Consecutive feature cards are separated by `space-md` (16px); distinct functional sectors use `space-xl` (32px).

## Elevation & Depth

Visual hierarchy does not use murky drop shadows. Instead, it relies on refractive glass layers, precision optical edge highlights, and deep ambient dispersion.

### The Glass Surface Recipe
- **Surface Material:** `background: rgba(255, 255, 255, 0.72)`.
- **Backdrop Dispersion:** `backdrop-filter: blur(24px) saturate(160%)`.
- **The Hairline Perimeter:** `border: 1px solid transparent; border-image: linear-gradient(180deg, rgba(255, 255, 255, 0.9) 0%, rgba(203, 213, 225, 0.35) 100%) 1`.

### Ambient Shadow Levels
- **Level 0 (Flat Ground):** Native off-white `#F8FAFC`, zero shadow.
- **Level 1 (Sub-Panel / List Items):** `box-shadow: 0 4px 20px -2px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Standard Glass Containers):** `box-shadow: 0 8px 32px -4px rgba(15, 23, 42, 0.05), 0 2px 8px -2px rgba(15, 23, 42, 0.02)`.
- **Level 3 (Modal Sheets & Active Command Triggers):** `box-shadow: 0 20px 48px -8px rgba(15, 23, 42, 0.08), 0 4px 16px -2px rgba(15, 23, 42, 0.04)`.

## Shapes

The geometric signature uses true Apple-style squircle curvature (`continuous` corner smoothing) to maintain refined, non-mechanical corners across glass planes.

- **Primary Containers & Master Glass Modules:** 24px corner radius (`1.5rem`).
- **Interactive Buttons & Nested Tiles:** 16px corner radius (`1rem`).
- **Data Pills, Micro-Status Badges, Action Pills:** 9999px fully rounded pill caps.
- **Micro-Form Elements (Inputs, Checkboxes):** 10px corner radius (`0.625rem`).

## Components

### Buttons
- **Primary Action (Command Obsidian):** Background `#0F172A`, text `#FFFFFF`, height 52px, corner radius 16px. Understated top inner edge specular highlight: `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. Active state: transforms to `scale(0.985)`.
- **Secondary Accent (Precision Crimson Action):** Background `#DC2626`, text `#FFFFFF`, height 52px, corner radius 16px. Reserved for automated liquidations or decisive capital commits.
- **Glass Secondary Button:** Background `rgba(255, 255, 255, 0.65)`, border 1px hairline gradient, text `#0F172A`, 24px blur.

### Cards & Wealth Containers
- **Core Glass Tile:** Curved 24px squircle, milky backdrop blur (24px), layered over ambient rose `#FFE4E6` and slate `#F1F5F9` radial blooms. Border uses the hairline vertical gradient. Inner padding: 20px or 24px.
- **Automated Ledger Tile:** Ultra-thin separation without divider lines; uses 8px intra-item spacing and `rgba(255, 255, 255, 0.45)` interactive hover/press states.

### Chips & Metrics Pills
- **Yield Status Pill:** Height 28px, corner radius 9999px, padding 4px 12px. Background `rgba(5, 150, 105, 0.08)`, border `1px solid rgba(5, 150, 105, 0.20)`, label `label-sm` in `#059669`.
- **Category Filter:** Height 36px, corner radius 9999px, padding 8px 16px. Background `rgba(255, 255, 255, 0.8)`, border `1px solid rgba(226, 232, 240, 0.8)`, typography `label-md` `#64748B`. Selected state: `#0F172A` fill with `#FFFFFF` text.

### Form Inputs
- **Field Framing:** Height 56px, corner radius 16px, background `rgba(255, 255, 255, 0.60)` with 16px blur, border `1px solid rgba(203, 213, 225, 0.60)`.
- **Focus State:** Border color shifts to `#0F172A` with a soft optical halo `0 0 0 3px rgba(15, 23, 42, 0.06)`. Input value set in `Inter` 16px tabular figures.

### Selection Controls
- **Switches (Autonomous Controls):** Width 50px, height 30px, fully rounded (capsule). Track: `rgba(203, 213, 225, 0.5)` when inactive, `#0F172A` when engaged. Thumb: 26px pure white circle with 1px hairline border and `0 2px 8px rgba(0, 0, 0, 0.12)`.
- **Checkboxes:** 20×20mm square with 6px squircle radius. Selected state uses Obsidian `#0F172A` fill with a pristine white hairline vector check.
